# Changelog

This file records the public release history of the Agentic Process Protocol specification suite.

**Format:** each entry corresponds to a tagged coordinated baseline (e.g., `APP-2026-10-RC1`). Entries are added at tag time, never rewritten after. The authoritative content for each release is in `/releases/<baseline-id>/`.

**Change sources:** entries are assembled at release time from the closed Issues, merged PRs, decision records in `/decisions/`, and `csl/Notices.md` entries since the last baseline.

**Document versions** cited in entries refer to the versions as fixed in that baseline's `MANIFEST.md` and `manifest.json`. The CHANGELOG summarises; the manifest is authoritative.

---

## Unreleased

The first coordinated baseline **APP-2026-10-RC1** is in preparation. Until it is tagged, this section remains the only source of record and documents are **not citable as the Specification**.

Pre-baseline notes will be captured here and migrated into the baseline entry at tag time.
